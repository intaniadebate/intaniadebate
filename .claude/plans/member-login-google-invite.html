ทิศทางที่ตกลงแล้ว

  • วิธี A: Astro บน Cloudflare Workers, ใช้ Better Auth และ D1 พร้อม invite list สำหรับ Google login
  • สมาชิกตั้งชื่อที่แสดงเองได้ สิทธิ์แยกเป็น member / admin / owner และผูกกิจกรรมกับรหัสผู้ใช้ถาวร
  • ผู้มีสิทธิ์โหวตมีแต้มรวมเท่ากันต่อรอบ แล้วแบ่งให้ candidate ตามช่วงเวลาที่กำหนด admin/owner กดหยุดได้
  • สมาชิกเห็นผลรวมหลังปิด ส่วน admin/owner ดูรายละเอียดรายคนได้ จึงไม่ใช่การโหวตแบบนิรนาม

ลำดับทำงาน

  1. พิสูจน์ runtime, OAuth, D1 และเงื่อนไขเขียนข้อมูลพร้อมกันบน preview
  2. ย้าย hosting และตรวจหน้า public, HTTPS, apex/www และ rollback
  3. เพิ่ม login, profile, invite, บทบาทสามระดับ และส่วน private
  4. ทดสอบสิทธิ์ ส่งต่อผู้ดูแล และซ้อมกู้ข้อมูลก่อนเปิดสมาชิก
  5. ยืนยันกติกาโหวต แล้วทดลองระบบคะแนนและ dashboard บน staging ก่อนเปิดรอบจริง

นี่เป็นเอกสารแผน ยังไม่เพิ่มระบบจริง ไม่เปลี่ยน DNS และไม่ deploy ประวัติแผน HTML เดิมอ่านได้จาก Git history ของ PR
