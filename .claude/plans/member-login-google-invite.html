ระบบสมาชิก สิทธิ์ และการโหวตของชมรม

แผนฉบับย่อแยกเว็บ public เดิมออกจากระบบสมาชิกใน private repo พร้อมตารางหน้าใหม่และการเก็บ/ดาวน์โหลด/สำรองข้อมูล เอกสารภาพรวมเปิดให้อ่านได้ โดยข้อมูลจริงและกุญแจลับไม่อยู่ในเอกสารนี้

อ่านแผนฉบับเต็ม พร้อมแผนผังระบบและข้อมูล

เปิดไฟล์ Markdown ใน checkout นี้ · ร่วมรีวิวใน PR #31

ทิศทางที่ตกลงแล้ว

  • สอง repo: เว็บหลัก Astro/GitHub Pages เดิม + เว็บสมาชิก Astro/Cloudflare Worker จาก private repo; ใช้ Google, Better Auth และ D1
  • สมาชิกตั้งชื่อที่แสดงเองได้ สิทธิ์แยกเป็น member / admin / owner และผูกกิจกรรมกับรหัสผู้ใช้ถาวร
  • ผู้มีสิทธิ์โหวตมีแต้มรวมเท่ากันต่อรอบ แล้วแบ่งให้ candidate ตามช่วงเวลาที่กำหนด admin/owner กดหยุดได้
  • สมาชิกเห็นผลรวมหลังปิด ส่วน admin/owner ดูรายละเอียดรายคนได้ จึงไม่ใช่การโหวตแบบนิรนาม

ลำดับทำงาน

  1. พิสูจน์ runtime, OAuth, D1 และเงื่อนไขเขียนข้อมูลพร้อมกันบน preview
  2. สร้าง private repo และ preview สำหรับเว็บสมาชิก โดยเว็บหลักยังอยู่ที่เดิม
  3. เพิ่ม login, profile, invite, บทบาทสามระดับ และส่วน private
  4. เพิ่ม JSON/CSV ตามสิทธิ์ สำรอง SQL ไป R2 private และซ้อมกู้ข้อมูลก่อนเปิดสมาชิก
  5. ยืนยันกติกา ซ้อมโหวต 30 คนและ dashboard บน staging แล้วค่อยเชื่อม subdomain/ปุ่มจากเว็บหลัก

นี่เป็นเอกสารแผน ยังไม่เพิ่มระบบจริง ไม่เปลี่ยน DNS และไม่ deploy ประวัติแผน HTML เดิมอ่านได้จาก Git history ของ PR
